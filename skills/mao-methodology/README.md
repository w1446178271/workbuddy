# mao-methodology — 毛泽东思想方法论工作法

把毛泽东思想中经实践检验的方法论体系（《实践论》《矛盾论》《反对本本主义》《论持久战》《中国革命战争的战略问题》《党委会的工作方法》等），蒸馏为 AI 可执行的工作流与 50 件思维工具，用于处理真实世界的真实问题与头脑中的思想问题。

## 它能帮你做什么

| 你的处境 | 它提供 |
|---|---|
| 头绪多、资源少、方向不明 | 六问分诊 + 主要矛盾判定，先排序再动手 |
| 计划总落不了地 | 五步工作流"查·析·聚·试·结"，从调查到复盘闭环 |
| 长期目标望而生畏 | 持久战三阶段打法，相持期有相持期的办法 |
| 团队协作低效 | 《党委会的工作方法》十二条的现代转译 |
| 挫败、迷茫、自我怀疑 | 思想问题作战表：认知、情绪、观念、意志、关系五类对症工具 |
| 信息过载、真假难辨 | "不做正确的调查同样没有发言权"——信源交叉验证纪律 |
| 初中生到退休人员都有 | 先采集情境档案，再按人群转译表说话——同一纪律，千张面孔 |

## 快速开始

### 安装

**CodeBuddy / Claude Code 等支持 skills 的环境**：将 `mao-methodology/` 整个目录放入技能目录（如 `~/.codebuddy/skills/` 或项目的 `.codebuddy/skills/`），重启会话即可。

**其他 AI 助手**：将 `SKILL.md` 全文粘贴到系统提示词或自定义指令中即可生效（references 目录按需附上）。

### 触发方式

对 AI 说以下任意一句即可激活：

- "用毛泽东方法论分析一下这个问题"
- "帮我抓一下主要矛盾"
- "实事求是地复盘这次失败"
- "这个问题用'查析聚集试结'走一遍"
- "这个问题复杂，请专家团会诊"（调用五席位会诊模式）

也可以不点名——当你的问题足够复杂（多目标、多约束、反复返工、陷入思想困惑）时，AI 应主动启用本 skill。

### 交互体验（怎么被服务）

加载本 skill 后，AI 不会上来就输出理论，而是遵循**「先诊断，后开方」**：

1. **听**：分析你的话语信号（急迫度、情绪、事实清晰度、关系人、有无数据）
2. **判**：预判问题属于六种模式中的哪种（或复合）
3. **问**：信息不足时最多问三个——*卡在哪？手里有什么？想要哪种帮助？*
4. **给**：出示帮助菜单让你选——马上出方案 / 先查清楚 / 深挖主要矛盾 / 先理心态 / 专家团会诊
5. **跟**：方案附检查点，主动约定回访，抓而不紧等于不抓

复杂与复合问题可召集**专家团会诊**：调查参谋、矛盾分析官（团长）、战略参谋、群众工作员、思想指导员五席位，按五步流顺序发言、相互质疑、团长汇总，**最终拍板权在你**。

**多模态支持**：你可以用文字、图片（截图/报表/照片）、视频、语音乃至实时通话（视平台能力）发起会诊——所有材料作为一手调查证据登记入报告；平台不支持某模态时会明确降级告知，绝不假装处理过；涉及他人隐私的材料会先提示脱敏。

## 权威性声明

1. **出处**：全部引文采用人民出版社《毛泽东选集》及人民网党史频道、人民网理论频道、中国共产党新闻网、中国军网、央视网等权威公开文献，逐条可回溯（见 `references/canon.md`）。
2. **总纲**：以 1981 年中共十一届六中全会《关于建国以来党的若干历史问题的决议》科学概括的"活的灵魂"（实事求是、群众路线、独立自主）为纲；本 skill 蒸馏的是其中贯穿的立场、观点、方法。
3. **定位**：方法论学习与工作工具，非政治文献汇编；涉及历史评价处一律采用《决议》规范性表述。
4. **误传防护**：网络流行的"毛主席语录"未经查证不得引用；已知以讹传讹的表述（如"没有重点就没有政策"）只列入辨析不进正文。宁少引，不错引。

## 设计原则（为什么它是这样）

- **真**：每件工具带可查证出处，附误传辨析——经得起较真的人检验
- **用**：每件工具=操作规则+适用条件，配有判定标准（如"怎么判主要矛盾"），不是口号
- **广**：按问题模式（不按职业）分诊，学生、职场人、管理者、教师、创作者、投资者都能找到入口
- **全**：六种问题模式 + 复合问题协议 + "先调查"元兜底——特殊问题不硬套，靠机制接住
- **自反**：一个反教条主义的方法论，自己绝不能变成新教条——所以"具体问题具体分析高于一切"写在第一条

## WorkBuddy 专家 / 专家团

除以 skill 方式加载外，还可以把方法论落地为智能体：

- **单专家版**：创建一个「会诊总主持」智能体，系统提示词粘贴 `experts/单专家版-会诊总主持.md` 即可，内置五席会诊模拟。
- **团队版**：按 `experts/README.md` 清单创建五个智能体（调查参谋/矛盾分析官·团长/战略参谋/群众工作员/思想指导员），按五步流接力会诊、互相质疑、团长汇总报告。

## 设计纪律

- **宁少引，不错引**：全部引文以 `references/canon.md` 为唯一依据，含常见误传辨析（如「谦虚使人进步」等表述的出处考订）。
- **先诊断，后开方**：AI 不直接输出理论长文，先分诊再给方案。
- **不预设，要采集；分诊看问题，转译看人**：诊断不按年龄贴标签，表达必须跟着人走（`references/audiences.md`）——只转译表达，不转译纪律。
- **最终拍板权在用户**：独立自主——任何分析与建议不替代用户决策。
- 本 skill 定位为思维工具箱，历史评价口径以 1981 年《关于建国以来党的若干历史问题的决议》为准。
