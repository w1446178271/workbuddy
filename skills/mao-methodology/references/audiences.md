# audiences.md — 人群转译表（同一工具，千张面孔）

> 用途：把 SKILL.md 的工具语言转译为眼前这个人的场景语言。**诊断层不看人，表达层必须看人**——问题模式六种与年龄无关，但话怎么说、例子举什么、颗粒度切多细，由档案决定。

## 〇、使用纪律（先读）

1. **档案从原话提取，禁止猜**：年轻人可能提养老，退休者可能玩新潮——按话语定档案，不按年龄刻板印象。拿不准且影响方案的，问一句即可。
2. **最小档案**：四项够用即停——①身份与年龄段 ②关键约束（钱·时间·家人·身体）③语言习惯（着急/冷静，术语/白话）④历史轨迹（首次还是老问题、试过什么）。不搞查户口。
3. **转译三件套**：换词汇表（用他生活里的东西打比方）、换颗粒度（年龄越小/越急，动作切得越碎）、换检查点（按他的节奏定回访，不按你的）。
4. **只转译表达，不转译纪律**：五步流顺序、出口检查点、引文核对——对谁都一样，一个字都不能少。

## 一、初中生（12–15 岁）

**阶段主旋律**：习惯刚成型、自我意识猛涨、被比较是日常、手机是第一注意力战场。

| 项目 | 转译要点 |
|---|---|
| 高频问题 | 执行类（计划坚持不住）+ 关系类思想问题（跟人攀比/闹别扭）+ 情绪类（考试焦虑、被点名） |
| 词汇表 | 课表、周考、错题本、闹钟、段位、小组、"我们" |
| 五步流说法 | 查＝把错题和卷子摆出来看｜析＝"这周只找最卡的那一章"｜聚＝一天只改一个习惯｜试＝先试三天，不用发誓坚持一学期｜结＝周五用五分钟看数据，进步多少算多少 |
| 颗粒度 | 动作切到"25 分钟一个番茄钟"；成功标准=可数的（背 15 个不是 50 个） |
| 检查点 | 短且密：三天一查，周五小复盘——陪伴感比道理有效 |
| 禁忌 | 忌大道理和宏大叙事（"你要明白学习是为了你自己"）；忌拿别人家孩子对比（触发关系类对抗）；忌一次改多个习惯（必失败，还搭上信任） |

> 对症示例（意志类）：不说"把大仗拆成小仗"，说："六门一起补就是撒胡椒面。这周只攻数学，每天 25 分钟，**周五我们一起看效果**——不用你咬牙坚持，定个闹钟就行。"

## 二、高中生（15–18 岁）

**阶段主旋律**：排名压力真实化、抽象思维已成型、能谈策略但反感说教、时间被课表锁死。

| 项目 | 转译要点 |
|---|---|
| 高频问题 | 规划类（分数目标/选科）+ 情绪类（排名波动）+ 决策类（强基/艺考/出国） |
| 词汇表 | 排名、一分一段、错题本、专项、月考、投入产出比 |
| 五步流说法 | 查＝近三次月考的分科数据｜析＝哪科"规定"了总分上限（B1）｜聚＝防御期保优势科、攻瘸腿科基础题（E4）｜试＝新方法单科试两周｜结＝月考投入产出比复盘 |
| 颗粒度 | 可以谈"阶段"与"战略"，他听得懂——但每阶段必须落到周计划 |
| 检查点 | 按月考节奏走，别自造节奏 |
| 禁忌 | 忌讲"刻苦"不讲方法（他缺的不是态度）；忌否定他已形成的判断（先接再析）；忌把焦虑当问题本身（焦虑多因方法无解，给方法即给情绪出口） |

## 三、大学生（18–25 岁）

**阶段主旋律**：选择第一次完全归自己（考研/就业/考公/gap）、同辈信息差大、自主管理首次失控、试错成本最低的窗口期。

| 项目 | 转译要点 |
|---|---|
| 高频问题 | 决策类（岔路口选择）+ 观念类思想问题（同辈比较/信息焦虑）+ 执行类（没人管了，节奏散了） |
| 词汇表 | 保研线、秋招、实习、绩点、信息差、试错成本、复利 |
| 五步流说法 | 查＝把两条路的真实数据查全（报录比、行业起薪、已毕业学长去向——这就是调查会 A1）｜析＝"怕错过"不是主要矛盾，主要矛盾通常是你还没拿到任何一条路的入场证据（B7 表面性）｜聚＝主攻一条，另一条转"敌进我退"周旋模式｜试＝先用最低成本拿证据（一段实习/一次模考/跟一次完整项目）｜结＝用拿到的证据重判，而不是用想象重判 |
| 颗粒度 | 以"拿证据"为单位，不以"做决定"为单位 |
| 检查点 | 每个证据动作定死截止日（学生最缺的是外部 deadline） |
| 禁忌 | 忌替他选（独立自主是他的必修课）；忌用"过来人"压人；忌把焦虑当选路依据——"因为怕A所以选B"是 B7 三忌的典型样本 |

## 四、职场新人（22–28 岁）

**阶段主旋律**：技能焦虑 + 协作摸不着门 + 第一份工作的去留放大镜 + 把领导当考官。

| 项目 | 转译要点 |
|---|---|
| 高频问题 | 执行类（活多且杂，不知先干哪个）+ 协作类（不敢开口/背锅焦虑）+ 决策类（三个月就想跑） |
| 词汇表 | 周报、优先级、向上同步、复盘、跳槽窗口、成长曲线 |
| 五步流说法 | 查＝记录一周时间去向与任务清单（C4）｜析＝"活多"里通常有一个真正的卡点：是任务本身，还是不敢问导致返工？（B4 内外因）｜聚＝每周只设一个主攻（把某个技能练到能教别人）｜试＝新协作习惯先在一个项目上用｜结＝周报就是现成的⑤结载体 |
| 颗粒度 | 用"周"为单位，和职场节奏同频 |
| 检查点 | 挂靠周报节奏，回访＝"这周报里哪条是主攻的？ |
| 禁忌 | 忌一开口就谈职业规划宏大叙事；忌把跳槽妖魔化或美化——跳不跳用《两案对比单》算，不用情绪定 |

## 五、中年骨干（29–50 岁）

**阶段主旋律**：多线作战（事业+房贷+子女+父母四线并行）、时间是最稀缺资源、试错成本最高、最怕"上有老下有小还撞上裁员"。

| 项目 | 转译要点 |
|---|---|
| 高频问题 | 逆境类（裁员/降薪/天花板）+ 规划类 + 决策类（跳槽/转型/副业）复合题 |
| 词汇表 | 现金流、刚性支出、主攻点、战役间隙、相持期、止损、第二曲线 |
| 五步流说法 | 查＝先盘现金流可支撑月数（数字先于情绪）｜析＝钱、方向、年龄、家庭期待里，哪个"规定"其余？（参照 cases.md 案例一）｜聚＝防御期只打有准备的仗，主攻点唯一（E1+E2）｜试＝副业/转型用"战役间隙"小步试（F7）｜结＝按月复盘数字，不凭感觉 |
| 颗粒度 | 以"月"为单位，方案必须兼容他的四线日程 |
| 检查点 | 月度复盘，回访问数字不问感受 |
| 禁忌 | 忌灌鸡汤（他懂的道理比谁都多）；忌全盘否定过往（F3 治病救人）；忌建议"裸辞全力以赴"（无视他的刚性约束＝没做调查） |

> 对症示例（意志类）：不说"加油坚持"，说："**相持期本来就好不了，硬挺不是办法，调节奏才是。**其余事进入'敌进我退'的周旋状态——不是不做，是不占你的主兵力。"

## 六、临退休与退休（50 岁以上）

**阶段主旋律**：身份转变（职场人→非职场人）、价值感重构、健康约束出现、家庭角色升级（带孙辈/照顾长辈）。

| 项目 | 转译要点 |
|---|---|
| 高频问题 | 逆境类思想问题（失落/没用了）+ 规划类（这几年怎么过）+ 关系类（家庭角色摩擦） |
| 词汇表 | 换个战场、火种、节奏、余热、身体本钱、带娃日程 |
| 五步流说法 | 查＝每天时间去哪了、什么事还有成就感（很多人答得出"忙"答不出"成就感"）｜析＝"没用了"是观念不是事实（B7 表面性：把"不再被需要"误当"没有价值"）｜聚＝定一个火种级的小事（F6：一门手艺、一片菜园、一个社群角色）｜试＝先试一个月｜结＝季度复盘，看状态不看KPI |
| 颗粒度 | 以"月/季"为单位，一切方案过一遍身体条件约束 |
| 检查点 | 宽松且固定：季度一聊，重在听状态 |
| 禁忌 | 忌说"享清福"（多数人不觉得这是福）；忌用年轻人的 KPI 逻辑套他；忌把失落当矫情——身份转变是真实的阶段课题，不是情绪脆弱 |

> 对症示例（情绪类·价值感）：不说"放下包袱"，说："**这不是退场，是换战场。**星星之火可以燎原——先把一件小事做成火种，状态是跟着'被需要'回来的。"

## 七、身份叠加：教育者与家长（教师 / 班主任 / 父母）

**特点**：他们的"群众"是学生和孩子（C5 的典型场景）；他们自己也是"被多方拉扯的人"（学校/家长群/孩子/自身成长）。

| 项目 | 转译要点 |
|---|---|
| 高频问题 | 协作类（班级管理、家校沟通、亲子）+ 规划类（教学节奏/自己发展）+ 情绪类（付出感与回报失衡） |
| 词汇表 | 课标、学情、班情、家校、课堂节奏、学情调查 |
| 转译核心 | 给学生/孩子做方案时，五步流里"查"＝学情调查（A1 的教育形态）；"群众路线"＝先听孩子要什么再定目标（cases.md 案例四） |
| 颗粒度 | 双层：给学生的动作按课时/周切；给家长自己的动作按学期切 |
| 禁忌 | 忌把"为你好"当调查结论（无调查的发言权）；忌替孩子做决定（C5 红线：不是代言） |
