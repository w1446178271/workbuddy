# maps.md — 中西方法论映射表与历史战例对照

> 用途一：让熟悉西方管理学/工具方法的用户三秒理解本 skill 对应什么。用途二：历史战例为每个抽象工具提供"原始用法"锚点，增强理解与记忆。

## 一、中西方法论映射表

| 毛泽东方法论 | 西方对应框架 | 相同点 | 差异点（毛泽东方法论的独有强调） |
|---|---|---|---|
| 实事求是 | 第一性原理（First Principles） | 都反对从类比和权威出发，回到事实底层 | 更强调"详细地占有材料"的调查功夫，而非纯逻辑推演 |
| 决策链（侦察→判断→决心→部署） | OODA 循环（博伊德） | 观察—判断—决策—行动同构 | 明确指出计划建立后仍是认识过程，即 OODA 的闭环修正被制度化 |
| 试点推广（一般和个别相结合） | 精益创业 MVP、A/B 测试 | 小步验证再放量 | "波浪式推广"与"看来很慢其实是快"的节奏论 |
| 批评与自我批评 | 复盘 / Retrospective（敏捷） | 结构化总结改进 | 强调"治病救人"——对人帮助导向，防复盘变追责 |
| 群众路线 | 用户导向 / Design Thinking | 以使用者为中心 | "从群众中来"是认识论（正确的认识只能来自一线），不只是需求收集 |
| 胸中有"数" | 数据驱动决策（DDDM） | 用数量分析说话 | "基本数量分析"是决策**资格**——没数字不得主观决定 |
| 解剖麻雀 | 深度个案研究 / Case Study | 从典型推一般 | 明确"不需要解剖每一只"——典型性优先于样本量 |
| 主要矛盾 | 关键驱动因素 / 80/20 法则 | 抓少数关键 | 给出判定标准：看哪个矛盾"规定或影响其他矛盾" |
| 集中优势兵力 | Focus / 资源聚焦 | 一次做好一件事 | "伤其十指不如断其一指"——追求歼灭战（彻底解决）而非击溃战（留尾巴） |
| 持久战三阶段 | 变革曲线 / Gartner 炒作周期 | 分阶段换打法 | 指出"相持期是转变的枢纽"——最难处恰是胜负手 |
| 弹钢琴 | 多线程统筹 / OKR | 主次配合有节奏 | 十个指头"不能有的动有的不动，也不能同时按下去" |
| 统一战线 | 生态合作 / 联盟战略 | 联合的力量 | "把朋友搞得多多的"——团结对手阵营中可争取的部分 |
| 不打无准备之仗 | Checklist / 风险管理 | 事前清单化 | 与"把握性评估"绑定：把握不足先造条件，而非降低目标硬上 |
| 独立自主 | 核心竞争力 / 自力更生 | 立足自身 | "学一切人的长处，但以我为主、为我所用"——开放学习与自主性的统一 |

## 二、历史战例对照（工具的"原始用法"）

| 战例/事件 | 核心工具 | 过程要义 | 现代对应 |
|---|---|---|---|
| 《湖南农民运动考察报告》（1927） | A1 调查先行 | 32 天步行 5 县，得到与书斋结论完全不同的判断，成为后来土地革命政策的依据 | 一线调研颠覆办公室假设 |
| 寻乌调查（1930） | C1 正确调查、C2 解剖麻雀 | 与 11 名各阶层代表 20 天访谈，商业、土地、交通逐项建档，8 万字报告 | 深度用户访谈的教科书 |
| 反"围剿"与四渡赤水（1935） | E7 你打你的我打我的 | 不与优势敌军硬拼，以机动调动敌军，在运动中创造局部优势 | 以节奏主动权对抗资源劣势 |
| 《论持久战》预言三阶段（1938） | E4 阶段论、A4 预见 | 驳"亡国论""速胜论"两种极端，预判战争全程并给出各阶段打法——其后历史进程与预判高度吻合 | 长期项目的里程碑规划 |
| 延安整风（1942–1945） | 反对本本主义、批评与自我批评 | 全党整顿主观主义、宗派主义、党八股；确立实事求是思想路线 | 组织的认知纠偏与文化重建 |
| 三大战役（1948–1949） | E1 集中优势兵力、E2 不打无把握之仗 | 每战形成局部绝对优势，歼灭敌重兵集团；辽沈、淮海、平津依次孤立对方 | 战略级资源聚焦与排序 |
| 七届二中全会（1949.3） | F2 两个务必、党委会十二条 | 胜利前夕立规矩：防骄傲、定工作方法 | 成功时刻的纪律设计 |

### 反面教材（为什么这套方法强调"反对"什么）

| 教训 | 违反的工具 | 后果与启示 |
|---|---|---|
| 王明教条主义（1931–1934，照搬苏联经验与共产国际指示） | B3 具体分析、A1 调查先行 | 脱离中国实际的指挥导致根据地损失惨重（含湘江战役的惨重代价）——**本本主义不是学术错误，是会流血的错误**。"以为上了书的就是对的"被实践证伪，这正是《反对本本主义》写作的直接背景 |
| 湘江战役式的硬拼消耗 | E1/E5 | 得失相当的消耗战是战略大忌——"力求避免打那种得不偿失的、或得失相当的消耗战"（十大军事原则第四条后半） |
| 速胜论与亡国论（1938 两种社会思潮） | E4、F5 | 同时高估与低估自己都会导向错误打法；预见必须建立在对矛盾双方的冷静盘点上 |

> 反面教材的使用规则：分析历史教训时对事不对人，落点在"机制上如何防再犯"（F3 惩前毖后、治病救人）。

## 三、使用建议

1. **入门用户**：先看映射表第一列与自己熟悉的框架对上号，再回 SKILL.md 学操作规则。
2. **深度用户**：历史战例用于向团队讲解决策逻辑时做类比锚点——抽象原则 + 具体战例 = 可传播的决策语言。
3. **讲授者**：每个工具按"引文（canon.md）→ 战例（本文件）→ 现代案例（cases.md）"三段式备课，形成完整证据链。
