# cases.md — 实战案例库

> 每个案例按五步工作流"查·析·聚·试·结"演练，标注所用工具。案例均为真实世界高频场景，职业无关化处理；"群众"在不同场景中指代不同对象（见 SKILL.md 分诊路由表）。**案例八至十一为人群转译示范**（初中生/大学生/退休/职场新人）——同一套工具纪律，针对不同人群的表达全转译（转译表见 `audiences.md`）。

## 案例一（主案例·复合问题全流程）：35 岁被裁员，房贷在身，要不要转行？

**问题模式**：逆境 + 决策 + 规划（三重复合）→ 触发**复合问题协议**：先拆矛盾，不急着回答。

**① 查**（A1 调查先行、C4 胸中有数）
- 事实盘点：存款可支撑月数、每月刚性支出、可变现技能清单、目标行业招聘量与薪资带（查数据，不凭印象）、社保断缴政策
- 头脑盘点：当前最恐惧什么（先 F4 放下包袱，把情绪与事实分开存放）

**② 析**（B1 主要矛盾判定、B2 主要方面）
- 矛盾清单：现金流生存压力 / 职业方向迷茫 / 年龄焦虑 / 家庭期待 / 市场环境
- 主要矛盾判定：**现金流生存压力**——它规定着其余一切（没有它，转行可以从容试错；有了它，任何选择的时间窗都被压缩）
- 主要方面：矛盾双方中"收入中断"是主导方面 → 问题性质是**生存问题叠加转型问题**，不是单纯的心理问题
- 与当事人确认判定后再继续（协议要求）

**③ 聚**（E1 集中优势兵力、E4 持久战阶段论、E2 不打无准备之仗）
- 阶段判定：当前是**战略防御期**——此阶段打法不是"立刻转型成功"（速胜论），而是"守住现金流 + 小成本试探方向"
- 准备清单：过渡性收入方案（咨询/接单/兼职）、转行目标行业 3 个候选、每月试错预算上限
- 主攻点只定一个：**先让现金流转正**。转行学习用"战役间隙"推进（F7 休整也是战略）

**④ 试**（C6 试点推广、A5 实践循环、A7 滚动修正）
- 不辞职赌转行，也不躺平：用接单/兼职小规模试新方向，30 天一个检查节点
- 每节点对照实际反馈修正假设（"计划建立之后仍是认识过程"）

**⑤ 结**（B5 两点论、F3 惩前毖后治病救人）
- 数量复盘：现金流月数变化、试单成功率、技能增长项
- 批评与自我批评：上份工作中哪些是环境、哪些是自己可改的（B4 内外因，先看内因但不苛责）
- 经验升为方法：**"防御期只打有准备的仗，反攻期才追歼灭战"** → 进入下一循环

> 教学要点：此案例展示"复合问题先拆矛盾再定序"与"阶段决定打法"两个核心动作。任何职业的逆境+决策复合题，结构同此。

## 案例二（诊断类）：项目连续延期，越加班越糟

**模式**：诊断类。工具组：A1→A2→B1→B2→D6。

- **查**：不做"大概是因为人手不够"的判断。列出延期记录（每次延期多少天、卡在哪个环节）、需求变更次数、沟通记录（D7 胸中有数）
- **析**：矛盾清单——人手 / 需求反复 / 排期方法 / 跨部门依赖 / 激励机制。判定主要矛盾：**需求反复变更**（它规定着排期失效、加班无效、士气下滑三个次生矛盾）。主要方面：变更的发起方与流程缺失是主导面 → 性质是**流程问题**，不是态度问题（B2 定性，防止错把流程病当人病治）
- **聚**：主攻一处——建立需求冻结与变更评审机制（E1 歼灭战，不搞六项整改齐上）
- **试**：先在一个小组试点两周（C6），拿到数据再推广——"逐步推广，看来很慢，其实是快"
- **结**：延期天数环比、变更次数环比；D6 抓紧：机制执行有闭环回音，否则"抓而不紧，等于不抓"

> 常见误用警示：跳过①查直接开会归因于人 → 违反 A1；整改措施一次上五项 → 违反 E1 平均主义之戒。

## 案例三（规划类·学生）：高三一年，成绩中游怎么提？

**模式**：规划类 + 执行类。工具组：E4→B1→E1→A5。

- **析**：矛盾清单——六科瘸腿 / 时间不够 / 方法低效 / 心态波动。主要矛盾判定：**两门瘸腿主科**（它们规定着总分上限与信心水平）
- **聚**：阶段论——秋季（防御）：稳住优势科，主攻瘸腿科基础题；寒假（相持）：最艰难期，也是转变的枢纽，专项突破中档题；春季（反攻）：套卷实战。每阶段打法不同（E4 换打法）
- **试**：新方法先在单科试两周，错题本数据说话（C4），有效再推广到其他科
- **结**：每次月考复盘"投入产出比"最高的动作，下月加码
- 心态线：F6 星星之火（名次从 200→150 也是燎原起点）、E5 战略藐视战术重视（大考敢打，每道题如履薄冰）

## 案例四（协作类·教师/家长）：孩子成绩下滑还顶嘴

**模式**：协作类 + 诊断类。工具组：A1→C5→"两类矛盾"→F3。

- **查**：先调查再定性——找班主任、同学、孩子本人多方了解（C1 正确调查），看作业与试卷的具体错点。**禁止一上来就批评**（无调查的发言权是 A1 红线）
- **析**：主要矛盾常常不是"态度差"而是某个具体卡点（如某章知识断层、同伴关系、睡眠）。先问"这是能力问题、方法问题还是情绪问题"（B2 定性）
- **定性关键**：孩子的问题属于**认识分歧/成长问题，不是敌我矛盾**——"两类矛盾要区分"，用帮助不用斗争（"惩前毖后、治病救人"）。把顶嘴理解为防御反应而非立场对抗
- **聚**：主攻一个卡点，一次只约定一个改变（F6 小胜养信心），从孩子自己的目标出发而非家长的目标（C5 从"群众"中来到"群众"中去：先听他要什么）
- **结**：每周一次 15 分钟复盘谈话，只谈进步与下一个改变，不翻旧账（F3）

## 案例五（逆境类·创作者）：长稿写了三万字卡死，越看越觉得垃圾

**模式**：逆境类 + 规划类。工具组：F4→B4→E4→E1。

- **头脑诊断**（思想问题作战表）：这是情绪类（气馁）+ 观念类（拿初稿当终稿评判）复合
- **对症**：F4 放下包袱——初稿的使命是被改，不是被赞美；E5 去魅——"写不完"是纸老虎，把它拆成章节清单后恐惧减半
- **析**：卡死的真实原因通常不是"文笔差"（表面性，B7），而是结构断层或素材不足（要回①查补调查：缺哪部分材料就去采哪部分）
- **聚**：按"相持期"打法：停止从头重写（速胜论的反面是全盘自弃），每天只推进固定字数，集中攻最卡的一章（E1）
- **结**：每周统计推进量（C4 用数据对抗"我觉得全是垃圾"的感觉——情绪不产生数据）

## 案例六（协作类·管理者）：会议越开越长，决定越开越少

**模式**：协作类。工具组：D2/D4/D8/D9/D12。

按《党委会的工作方法》逐条改造：
1. D8 安民告示：提前一天发议程与材料，无议程不开会（"兵马已到，粮草未备"是原文点名批评的现象）
2. D2 问题摆上桌面：分歧当面摆事实，禁止会后背后议论
3. D4 不懂的问下级：决策者先听一线数据再表态，不轻易赞成或反对
4. D9 精兵简政：每次会只解决一两个问题，输出简明决议
5. D12 划清界限：决议必须写清"做什么、谁负责、何时完"（主次与比例讲清楚）
6. D10 团结反对者：每个议题必须先听不同意见再表决

> 检验：一个月后统计"会议时长 / 决议数量"两个数（D7），用数字验收改造效果。

## 案例七（时代绑定）：AI 给的答案看着头头是道，怎么防止被它带偏？

**模式**：决策类 + 观念类思想问题。工具组：A1→C1→B7。

- 观念矫正：AI 的输出也是"材料"，不是"结论"——"本本"从书本变成了模型输出，本本主义换了载体："以为上了机的就是对的"= 新版"以为上了书的就是对的"
- 操作：①关键结论要求 AI 给出来源，人工抽验（C1 交叉验证）；②多渠道对冲：AI 之外必须有一个独立信源（A1）；③三忌自检：这个答案是否只有一面（B7）？是否过于顺滑没有反例？④自己的判断要用自己的数据落地检验（A5 实践循环）
- 一句话药方：**让 AI 当侦察兵，不当指挥员**——决策链（A3）里，决心必须是自己的（F8 独立自主）

## 案例八（执行类·初中生，人群转译示范）：计划每天背 50 个单词，三天就断

**模式**：执行类 + 意志类思想问题。工具组：B1→E1→C6→D6；人群转译见 `audiences.md` 第一节。

- **查（先查用户）**：档案——初一学生，约束=作业后只有约 40 分钟自由时间；历史=计划常三天内失效；语言习惯=吃"具体、短、带陪伴感"的话。查实每天实际可用时段与当前词汇量（不凭"他偷懒"开局——A1 红线）
- **析**：矛盾清单——目标量 / 时间 / 反馈周期 / 手机争夺。主要矛盾：**目标颗粒度与反馈周期错配**（50 个/天 + 一月后见分晓 = 任何意志都撑不住）。主要方面：目标错是主导面，不是态度错（B2 定性，防止错把方法病当人品病）
- **聚**：主攻一个：英语词汇这一项。目标改 15 个/天（E1 歼灭战）；手机交给闹钟后的 25 分钟番茄钟规则
- **试**：只试三天（C6 试点的最小单位按初中生节奏切）；成功标准可数：三天后听写 ≥13/15
- **结**：周五用五分钟一起看听写记录（D6 闭环 + 数据对抗"我觉得没用"）；三天成了加到 20 个，小胜养意志（F6）

> 转译要点：同一工具链对成年人说"拆小仗、建闭环"，对初中生必须落到"每天 15 个不是 50 个，周五我们一起看"。**纪律不变（仍有出口检查点），表达全转译。**

## 案例九（决策类·大学生，人群转译示范）：考研还是就业，两头都怕错过

**模式**：决策类 + 观念类思想问题。工具组：A1→B7→C6→七·六两案对比单；人群转译见 `audiences.md` 第三节。

- **查（先查用户）**：档案——大三，约束=家庭可支撑读研但不宽裕；已试过=搜集了大量经验帖（注意：刷帖不是调查，A1 要一手证据）。查实：目标院校近三年报录比、目标行业本校就业去向、学长学姐一手访谈（这就是调查会）
- **析**："怕错过"是情绪不是矛盾（B7 表面性）。真矛盾：**两条路都还没有入场证据**——没有一手证据前，任何选择都是想象对想象
- **聚**：主攻=用一个学期拿到一条路的一手证据（一段对口实习或一次完整备考周期模考）；另一条转"敌进我退"周旋状态（E10）
- **试**：证据动作定死截止日；期间填《七·六两案对比单》——两案主要矛盾不同，先分诊再选，禁止拿想象填表
- **结**：拿证据重判（不是拿情绪重判）；经验入账："岔路口先造证据，再造决定"

## 案例十（逆境类·退休，人群转译示范）：刚退休三个月，每天没精神，觉得自己没用了

**模式**：逆境类 + 情绪类/观念类思想问题。工具组：F4→B7→F6→F7；人群转译见 `audiences.md` 第六节。

- **查（先查用户）**：档案——退休三个月，身体健康可中等活动，家庭角色升级（开始带孙辈但觉得"只是搭手"）。查实：每天时间去向、过去三十年最有成就感的二三事（多数人答得出"忙"答不出"成就感"，这一问是关键调查）
- **析**："没用了"是观念不是事实（B7 表面性：把"不再被职场需要"误当"没有价值"）。主要矛盾：**价值感断供**，不是健康也不是家庭矛盾
- **聚**：定一个火种级主攻（F6）：一门手艺、一片菜园、一个社群角色——从"最有成就感的事"里长出来，不凭空安排
- **试**：先试一个月；身体条件约束全程置顶（方案必须过身体关）
- **结**：季度复盘看状态不看 KPI；用"被需要回来了"对抗失落，不灌"享清福"式的空话

> 转译要点：同一 F4 放下包袱，对中年人讲"卸下过往失误"，对退休者讲"不是退场，是换战场"。

## 案例十一（执行类·职场新人，人群转译示范）：第一份工作干得不开心，三个月就想跳槽

**模式**：决策类 + 协作类。工具组：A1→B4→七·六两案对比单→D6；人群转译见 `audiences.md` 第四节。

- **查（先查用户）**：档案——入职三个月，约束=房租靠这份工资。查实一周时间去向与任务清单（C4）；"不开心"具体是哪三件事（禁止用情绪总量做决策输入）
- **析**：B4 内外因——是任务本身错配，还是不敢问导致返工被批（新人最常见的隐形卡点）？先看内因可改的，但不忘外因真实存在的部分
- **聚**：主攻一处：先修"卡点能力"（如提问机制：每半天集中问一次，D3 互通情报）；跳槽念头不压制也不放大，转入周旋
- **试**：新习惯在一个项目上跑两周；填《两案对比单》——重点比机会成本与可逆性（三个月履历 vs 当前现金流约束）
- **结**：两周后用事实重判：是环境问题（可考虑跳）还是方法问题（跳了重演）。跳与不跳都成立，**但必须由证据拍板，不由情绪拍板**（F8 独立自主）

## 案例库使用规则

1. 新案例进入本库前，须通过"四性自检"：真实性（场景与数据合理）、指导性（工具组合明确）、可迁移（去掉职业细节后结构可复用）、思想性（是否覆盖了头脑内的问题）。
2. 每个案例结尾必须回答："下次遇到同类问题，最先做的三个动作是什么？"
3. 使用者贡献的真实案例（脱敏后）可提交给 skill 维护者，经核实后纳入——这是 skill 自身的"实践—认识—再实践"（见 README 共创接口）。
