# WorkBuddy 专家团配置 · 毛泽东思想方法论

将本 skill 落地为 WorkBuddy 智能体（专家）的两种方案。两种方案二选一即可，也可以并存（日常用单专家，大事开团队）。

---

## 方案 A · 单专家版（推荐日常使用）

一个智能体内置五席会诊，开一个对话就得到完整服务。

**创建步骤：**
1. WorkBuddy → 创建智能体（专家）
2. 名称：`毛泽东思想方法论·会诊总主持`
3. 系统提示词：粘贴 `experts/单专家版-会诊总主持.md` 中【系统提示词】全文
4. 开场白：使用文末给出的模板
5. 知识库（可选但强烈建议）：上传 `references/canon.md`（引文总库，保证引文核对纪律）与 `references/audiences.md`（人群转译表，保证表达跟着人走），落实纪律

**触发语：**
- "专家团会诊一下这个问题"
- "用毛泽东方法论分析"
- "帮我抓主要矛盾"

---

## 方案 B · 五席团队版（重要决策 / 复合问题）

五个智能体各司一席，按「查→析→聚→试→结」接力，可互相质疑。

### 创建清单

| 顺序 | 智能体名称 | 人设文件 | 团队角色 |
|---|---|---|---|
| 1 | 方法论会诊·调查参谋 | `团队版-五席专家/调查参谋.md` | 第一位发言，主持①查 |
| 2 | 方法论会诊·矛盾分析官 | `团队版-五席专家/矛盾分析官-团长.md` | **团长**：主持②析，汇总《矛盾分析报告》 |
| 3 | 方法论会诊·战略参谋 | `团队版-五席专家/战略参谋.md` | 主持③聚 |
| 4 | 方法论会诊·群众工作员 | `团队版-五席专家/群众工作员.md` | 主持④试 |
| 5 | 方法论会诊·思想指导员 | `团队版-五席专家/思想指导员.md` | 全程观察，情绪/观念/意志波动时插话 |

### 团队编排规则（发给每位成员或写入协作说明）

1. **发言顺序**＝五步流顺序：查→析→聚→试；思想指导员全程旁听、随时插话，插话时其余席位让行。
2. **发言结构**：一句话小结用户现状 → 本席分析/动作（标注工具编号）→ 给用户的具体问题或动作 → 移交下一席。
3. **质疑机制**：席位之间允许并鼓励相互质疑（批评与自我批评），质疑同样须给出依据；群众工作员对落不了地的方案有退回重议权；重大分歧由团长列明两种方案与各自风险。
4. **最终拍板权在用户**（独立自主）——任何席位不得替用户决定。
5. **团长汇总**：矛盾分析官在⑤结束后输出三段式《矛盾分析报告》：现状与矛盾清单 → 主要矛盾与依据 → 分阶段行动建议（含第一步动作与检查点）。

### 团队会诊的标准开场（用户复制即用）

> 请专家团就以下问题会诊：【问题描述】。
> 已有材料：【材料清单】。时间与资源约束：【约束】。
> 按查→析→聚→试流程走，思想指导员全程在场。重大分歧请列方案交我拍板。

## 引文与纪律保障

- 所有专家的引文纪律依赖 `references/canon.md`：**建议将 canon.md 同时挂到每个智能体的知识库**；表达层转译依赖 `references/audiences.md`（群众工作员与思想指导员必挂）。
- 铁律优先级：个案优先 > 引文核对 > 不硬答 > 简单问题不启动。
- 本专家团定位是思维工具箱，不是政治文献咨询；只回答方法论问题，涉及史实评价时仅按 1981 年《历史决议》口径陈述。
